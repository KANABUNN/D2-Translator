# スラング候補の整理メモ

- 最終候補: 266語義、92別名、84資料。すべて `en-ja` / `Any` / `pending`。
- 日本語訳、注意書き、英語例文は独自作成。コミュニティ辞書や利用者解説は公式ゲーム用語の確定訳とは分ける。
- `GTG`, `NM`, `TL;DR`, `I'm cooked`, `no shit`, `no worries`, `all good`, `gotcha`, `RIP`, `yeet`, `PM`, `OT`, `tryhard` は複数の語義を分離。同じ表記が一致しても一方へ強制しない。
- `G2G` は退出と準備完了の両方に別名登録。`PM` は個別メッセージと午後、`OT` は話題外と延長戦を分離。
- `GL` は励ましとグレネードランチャー、`FR` は本当にとフュージョンライフル、`OP` は投稿者と強すぎるの文脈が衝突する。D2側の候補と併存させる。
- `Discord` の通話・チャットサービスの語義を明示。パーク名「不和」と区別。`disc` は通常語や別略語との衝突が大きいため採用しない。
- `POG`, `Kappa`, `KEKW` 等のエモート名は名称も訳に残す。皮肉・悲しみ・喜びは固定しすぎず注意書きを添える。
- 既存サンプルの `d2.chat.gg`, `d2.chat.brb` は生成していない。`GGs` は別候補として収録。
- 広く一致しすぎる単独の `I`, `u`, `r`, `b`, `c`, `w`, `k`, `well`, `go`, `up`, `2`, `4` は除外。`based`, `bet`, `cap`, `cooked`, `washed` 等は可能な限り文句として収録した。
- 卑語・挑発は強さを注意書きに示し、友好的な挨拶に丸めない。集団属性への差別語リストは作成していない。
- `SRY` の `srry` は利用者辞書の検索本文、`soz` は直接確認できたWiktionaryで補助確認。非侮辱的な `tryhard run` はD2コミュニティの検索本文で用例を確認。すべてpendingを維持。
- `cuz` の理由を示す別表記 `cos/coz/bc/b/c` には別義の注意書きを付ける。特に `bc` は紀元前・地域名、`cos` は数学などと衝突する。
- APSUの検索索引には略語表があったが、直接URLが404だったため最終データの出典から除去し、該当項目は直接確認できたWiktionaryへ変更済み。
- これは文脈ヒントの候補辞書。実ゲームOCR、API翻訳、Claude実装での統合動作、悪意や皮肉の識別成功を証明するものではない。

## 確認の水準

1. 英日正式名称は、ルート担当が取得した Bungie Manifest の同一ハッシュで表示名または説明文を照合した。バージョンは `245114.26.10.13.2000-1-bnet.66137`。装備、パーク、サブクラス効果、勢力、NPC、敵ユニットの表記に使用。
2. 活動の略称を追加した20件では `DestinyActivityDefinition` の英日同一ハッシュを照合し、難易度の接尾辞を外して基本名を用いた。例: Vesper's Host の現行Manifest表記は **べスパーの宿主**（先頭はひらがな「べ」）。
3. LFG・レイド・PvP・ビルド俗語の出典は、Bungieの説明および投稿者自身によるReddit/コミュニティの解説・実体験を参照。出典一覧は用語群の意味・使われ方を辿るための参照であり、**全別名を1語ずつ各ページで確認できたという意味ではない**。編集による言い換え・複数形・綴り違いも含む。すべて人による承認前の候補として扱う。
4. `leeching`、`emanating`、`enlightened`、一部のレイド道具は、正式日本語名が独立して確認できないものについてローマ字由来の通称または効果説明で訳している。注記で正式表示名との違いを明記。
5. 古い記事も語義の資料として使用している。古いバランス値や武器推奨、古い攻略手順は辞書へ取り込んでいない。現在の実機・ゲーム内チャットでの受入確認は未実施。

## 多義性・統合時の注意

- RR: Raid Report と Raid Room を別語義にした。
- DR: 被ダメージ軽減と diminishing returns を別語義にした。
- one shot: 瀕死の敵の報告と一撃で倒す性能の両語義を保持。
- SR: スナイパーライフル / スカウトライフル、EA: 妬む刺客 / 妬ましい兵器、FF: 集束した憤怒 / 狂乱索餌を分けた。
- OP: 強すぎる / 元投稿者、GL: グレネードランチャー / good luck、FR: フュージョンライフル / for real、NM: normal mode / never mind・nothing much、LFG: looking for group / 歓声の let's freaking/fucking go は、ネットスラング側の語義と共存が必要。
- Rift（ウォーロックのリフト / 対戦の暁光）、Fragment（サブクラスのかけら / マップの破片）、Mercy（コールド / 試練の証の慈悲）、Survival（生存 / 対戦のライフリミット）、Elimination（排除 / 対戦のサバイバル）を区別する補完語義を追加。
- enlightened はクロタの最期 / 救済の庭園で別語義。Any条件だけでは活動を判定できないため、訳候補の注記を利用する。
- 固有名・効果名・一般語と同綴りの短語は、文脈依存を注記した。大文字小文字による区別は期待しない。
- no mic required / mic not required を独立収録。mic required の別名 have a mic は削除した。one shot の別名 he/she/they is/are one、recoil の別名 recoil direction、relay defense の別名 relay defender は削除した。
- 敵名の Captain / Knight / Wizard / Goblin / Hydra および複数形は、宿られ個体にも使われるため中立のカタカナ訳に修正した。勢力の修飾語を訳で付け足さない。
- 任意の短語を「常にこの意味」と置換する用途には向かない。既存の複数語義・注記・翻訳コンテキストとして渡す設計に合わせる。
