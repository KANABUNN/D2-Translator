# 残存制限一覧

2026年10月25日、Phase 5 時点（利用者の確認結果を反映）。仕様書 22 章 Phase 5 の「残存制限一覧」と 21.2 の条件付き評価に対応する。受入の判定は [受入試験の証跡](phase5/acceptance.md) を参照。

## 未検証・未実施

| 項目 | 内容 | 関連 |
| --- | --- | --- |
| 8 時間の実機試験の数値 | 利用者が 8 時間の実機試験を完了したと報告したが、判定表（診断記録の集計）は残っておらず、P10〜P13 の数値の記録はない。ゲームなしの耐久試験は 60 分（と 2 時間）を開発機で行った | P10〜P13、T16、A10 |
| ゲームの性能への影響 | アプリの有無でフレーム時間を比べていない | P12 |
| 翻訳品質の記録 | 利用者の採点で基準を満たしたが、採点表はリポジトリにない。辞書の用例は未確認のまま | P08、P09、A04 |
| OCR と追跡の受入評価 | 利用者のスクリーンショット 3 枚（CER 4.2%）と模擬画面での確認だけ。200 枚、20 本の録画による評価をしていない | P05〜P07、A03 |
| 遅延の受入評価の記録 | 実機の P01〜P03 の数値（各 500 件以上）はリポジトリにない。模擬画面では P01 899 件で p95 77ms | P01〜P03、A10 |
| アンチチートとの共存 | 実機で通常どおり遊べたことは利用者が確認したが、長期間の観察記録はない。共存は許可や将来の保証を意味しない | T17、A11 |
| 更新と元の版へ戻す操作 | 署名した MSIX のインストールは利用者が確認した。次の版への更新と元の版へ戻す操作は実施していない（設定を書き換えないことは試験で確認） | A12、T18 |
| Windows 11 | 未確認。オーバーレイの映り込み除外（D25）の成否も未確認 | U02 |
| HDR、4K、ウルトラワイド、複数 GPU、混在 DPI | 未確認（仕様書 21.2 の拡張条件） | U08 |
| スクリーンリーダー | UI オートメーションで名前とアクセスキーが見えることは確かめたが、ナレーター等での読み上げは確認していない | T19 |

## 既知の制限

| 項目 | 内容 | 関連 |
| --- | --- | --- |
| 他プレイヤーの発言のチャンネル | 日本語クライアントは他プレイヤーの発言にチャンネル名を出さないため、Unknown とする。文脈では Unknown をどのチャンネルとも同じ会話とみなす | D15、D19 |
| 網目状の床の上の ROI | チャットが出ていない時、背後の模様が数字や記号の列として読まれ、発言として表示されることがある。アクティビティ内ではほぼ起きないため対処しない（利用者の判断） | Phase 4 |
| 1 文字の本文 | `y`、`n` 等の 1 文字の本文を取りこぼすことがある | Phase 2 |
| 薄れていくチャット | 表示から 5 秒を過ぎた読みの変化は訂正として採用しない。正しい訂正も採用されないことがある | D23 |
| オーバーレイの映り込み除外 | Windows 10 では透過ウィンドウに `WDA_EXCLUDEFROMCAPTURE` を使えない。ウィンドウを選んで取得すれば映り込まない。モニター全体の取得では ROI と重ならない位置に置く | D25 |
| 排他フルスクリーン | オーバーレイは表示できない。ボーダーレスかウィンドウ表示で使う | 4.2 |
| 取得対象の種別 | 選択 UI はウィンドウかモニターかを返さないため、フォーカス喪失時の停止はタイトルの比較で行う | D10、D24 |
| 推論量 | GPT-6 Luna の推論量は none に固定。low は選べない | D09 |
| 応答モデル | `gpt-6-luna` と完全に一致しない応答は採用しない（日付付き ID 等） | D21 |
| 料金 | 推計は 2026年10月24日の公表単価による。単価を利用者が登録する画面はない | D22 |
| 自動更新 | ない。更新は利用者が MSIX を入れ替える | 17.3 |
| トレイアイコン | ない。ホットキーの代替はメイン画面のボタン | D27 |
| 文字の拡大 | Windows の「テキストのサイズ」はアプリの画面に反映されない。表示の拡大（ディスプレイの拡大率）は反映する。オーバーレイは文字の大きさを設定で変えられる | 17.2 |
| 診断の設定 | 診断記録を止める設定（`diagnostics.level`）は設定画面になく、`settings.json` を直接書き換える | D28 |
| 公開配布の証明書 | 自己署名の配布物は、受け取った人が証明書を信頼しないとインストールできない | D30 |
