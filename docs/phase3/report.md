# Phase 3 実施記録

仕様書 22 章 Phase 3「辞書、文脈、GPT-6 Luna 接続、推論量と費用の制御」の実施記録。記録日は 2026年10月24日。

## 実装したもの

| 項目 | 内容 | 仕様書 |
| --- | --- | --- |
| API 接続 | OpenAI Responses API（`POST https://api.openai.com/v1/responses`）を HttpClient で呼ぶ。リダイレクトを追わず、送信直前に送信先とモデルを検証 | 6.3、14.2、18.2 |
| 固定プロファイル | `gpt-6-luna`、`reasoning.effort=none`（D09）、`service_tier=default`、`max_output_tokens=1024`、`store=false`、`stream=false`、`background=false`、`tools=[]` | 6.3 |
| 構造化出力 | `text.format` の JSON Schema（strict、全項目必須、追加プロパティ禁止）。応答はローカルでも検証する | 14.2 |
| 応答の検証 | `status=completed` のみ成功。`output[0]` を仮定せず `output_text` を探す。拒否、打切り、スキーマ不一致、ID と revision の不一致、空、2000 文字超、64KB 超を成功にしない。応答モデルが `gpt-6-luna` でなければ TR05（D21） | 14.2 |
| エラー | 401/403 → TR01、429 → TR02、5xx・通信失敗・時間超過 → TR03、形式不正・拒否・打切り → TR04、モデル不可 → TR05。エラー応答の message は表示やログに流さない | 14.3 |
| 再試行と期限 | 全試行で 4 秒の期限。429 と一時的な障害だけ Retry-After を尊重して 1 回再試行。期限に収まらなければ再試行しない | 15.4 |
| 遮断 | 一時的な失敗が 5 回続いたら 30 秒遮断し、期限後は 1 要求で回復を確認 | 15.4 |
| 上限 | 1 分あたりの要求数（既定 60）、セッションの要求数（既定 1000）。到達したら外部翻訳だけを止め、取得と原文表示は続ける | 12、17.4 |

| 匿名化 | 話者名は送らず P1 等の一時 ID を使う。本文中の既知の名前、URL、メールアドレスを `⟦P1⟧`、`⟦URL1⟧`、`⟦MAIL1⟧` に置き換え、訳文で元の表記へ戻す（D14） | 9.2、18.1 |

## 試験

`dotnet test D2Translator.slnx` で 199 件すべて合格（3 回連続）。外部 API は呼ばず、偽の HTTP ハンドラーと偽の翻訳サービスを使った（仕様書 20.2）。

| 観点 | 主な試験 | 仕様書の試験 |
| --- | --- | --- |
| 固定プロファイル | 要求ボディの model、reasoning、service_tier、store、tools、text.format、キーが本文にないこと | T20 |
| 応答の検証 | 推論項目の後の output_text、拒否、打切り、未確認のモデル ID（`gpt-5`、日付付き ID）、スキーマ不一致、ID 不一致、2000 文字超、64KB 超 | T09、T20 |
| 障害 | 401/403/404、400 model_not_found、429 の再試行と Retry-After、insufficient_quota、5xx の再試行、通信失敗、期限超過、キー未登録で送信 0 件 | T09 |
| 調停 | クラウド無効で送信 0 件、名前の匿名化と復元、開始前の発言は手動のみ、自分の発言は翻訳しない、TR01 で停止し再設定で再開、キャッシュ、送信中の訂正で古い結果を破棄、セッション上限、記号の欠落で要確認 | T10、T11、T15 |
| 部品 | 文脈の件数・時間・文字数・セッション・チャンネル、遮断と回復確認、1 分あたりの上限、料金の推計（仕様書の例 0.0002 米ドル） | T10、T16 |
| 認証情報 | DPAPI の往復、ファイルに平文がないこと、削除時に旧版も消すこと、改ざんした値を開けないこと | T13 |

## 外部送信の範囲（利用者向けの説明と同じ内容）

- 送る: 他プレイヤーの発言の本文（名前、URL、メールアドレスは記号に置換）、関係する D2 辞書の項目、文脈を有効にした場合の直近の原文、一時 ID（P1 等）。
- 送らない: 画面の画像、話者の名前、API キー以外の設定、ローカルのファイル、自分の発言、システム表示。
- `store=false` は応答の状態保存を無効にするもので、OpenAI の不正利用監視のためのログの保持（通常最大 30 日）まで無くすものではない（仕様書 18.4）。
