# Phase 2 実施記録

仕様書 22 章 Phase 2「OCR、行追跡、辞書注釈、オフライン基盤」の実施記録。記録日は 2026年10月24日。

Phase 1 の実機確認で、日本語クライアントでは行頭のチャンネル表示とシステムメッセージが日本語のため、英語 OCR では記号列になることが分かった。Phase 2 ではこれを前提に OCR と行の解析を組み直した。

## 実装したもの

| 項目 | 内容 | 仕様書 |
| --- | --- | --- |
| 前処理 | OCR 前に ROI を2倍（最近傍法）に拡大。`ocr.preprocessing.scale`（1〜3） | 8.1 |
| 2言語 OCR | 本文の言語（en-US）とゲームの表示言語（`ocr.clientLanguage`、既定 ja）の両方で認識し、行ごとに合成（決定 D13） | 8.1 |
| 行の組み立て | 縦位置で行をまとめ直し、かな・漢字が2文字以上続く範囲は日本語 OCR、それ以外は英語 OCR の結果を使う | 8.2 の 1〜2 |
| 行の解析 | 自分の発言、他プレイヤーの発言、参加通知、システム表示、折り返し、入力欄を判定 | 8.2 の 3 |
| 発言の追跡 | 画面上の順序を保つ最長対応で前回までの発言と対応付け、下端に現れた候補だけを新着にする | 8.2、8.3 |
| 確定 | 200ms 以上同じ読みが続いたら確定。1秒で安定しなければ要確認 | 8.2 の 4 |
| 訂正 | 確定後に別の読みが 200ms 以上続いたら revision を上げて CorrectedText に置く。原文は上書きしない | 8.2 |
| 再開 | 停止から再開した時、停止中に増えた発言は新着にしない | 15.3 |
| 話者 | 話者名と参加通知の名前を端末内の一時 ID（P1、P2…）に対応付け、本文中の呼びかけを注釈する（決定 D14） | 9.2 |
| D2 辞書 | 仕様書 9.1 の用例を同梱辞書にし、単語境界と最長一致で照合。多義語は全語義を併記。`LF{n}M` は数字を保持 | 9.1 |
| 辞書の読み込み | 5MB、10000 項目、1項目 2000 文字の上限。制御文字、`{n}` 以外の置換記号、重複を拒否し、1件でも不正なら全体を取り込まない | 13.4、18.3 |
| 受信履歴 | メイン画面に確定した発言、状態（認識中、要確認、辞書注釈のみ、開始前から表示）、注釈を表示。最大 1000 件 | 11.2 |
| 評価ツール | `tools/D2Translator.Eval`。正解付き画像で文字誤り率を測る | 16.3 P05 |

## 日本語クライアントの表示形式（2026年10月24日、利用者のスクリーンショットで確認）

| 行の種類 | 表示例 | 解析結果 |
| --- | --- | --- |
| 他プレイヤーの発言 | `[Name#1234]: 本文` | Player。チャンネル名は表示されない |
| 自分の発言 | `[ファイアチーム]宛て: 本文` | Own。チャンネルは表示名から判定 |
| 自分の発言（ファイアチーム検索機能） | `To [ファイアチーム検索機能]: 本文` | Own（FireteamFinder） |
| 参加通知 | `Name#1234がチームチャットに参加しました。` | System。話者名を対応表に登録 |
| システム表示 | `チャット履歴が消去されました。` | System |
| 折り返し | 行頭の表示がない2行目以降 | 直前の発言へ結合 |
| 入力欄 | 最下行の `[ファイアチーム]宛て:` | 除外 |

他プレイヤーの発言は、ファイアチームとファイアチーム検索機能で話者名の色の濃淡だけが異なり、文字では区別できない。現時点では Unknown とする（決定 D15）。

## 評価結果

利用者のスクリーンショット3枚（他プレイヤーの識別番号は塗りつぶし済み）を開発機でだけ使い、本文と日本語の行を正解として測った。画像はリポジトリに入れていない。

| 画像 | 内容 | 文字誤り率 |
| --- | --- | --- |
| 自分の発言とシステム表示 | 5 行 | 2.4% |
| 参加通知と発言 | 3 行（本文のみ） | 13.7% |
| ファイアチームの会話 | 8 発言（本文のみ） | 1.5% |
| 合計 | 264 文字 | 4.2% |

- 2言語 OCR の導入前（英語 OCR のみ、行の解析なし）は同じ画像で 63.6% だった。
- 残る誤りは、1文字だけの本文（`A`、`N`）の読み落とし、`y` を `Y` と読んだもの、塗りつぶしの影響で名前と本文の境界が崩れた行。
- これは P05 の受入評価（200 枚以上、20000 文字以上）ではない。判定は「測定不能（データ不足）」とする。

結合試験では、日本語の行頭（色付き）と英語の本文（白）を描いた画像から、自分の発言、参加通知、他プレイヤーの発言を正しく解析できることを確認した。

## 評価ツールの使い方

```bash
dotnet run --project tools/D2Translator.Eval -- eval-data
```

画像（png/jpg）と同名の .txt を置く。正解ファイルの各行は、行全体を比べる場合はそのまま、本文だけを比べる場合は先頭に `> ` を付ける。

```text
[ファイアチーム]宛て: Need two more
> Sounds bugged
```
