# 操作説明

D2 Chat Translator 0.1.1（Phase 5）の使い方。版ごとの変更点は [変更履歴](../CHANGELOG.md)。仕様書 22 章 Phase 5 の「操作説明」。制限は [残存制限一覧](limitations.md)、インストールと更新は [配布、署名、更新](distribution.md) を参照。

## できること

- ゲーム画面のチャット欄を、Windows の画面取得と端末内の OCR で読み取り、発言ごとに表示する
- 原文の D2 用語（公式名称、略語）とネットスラングに注釈を付ける。辞書は 9,547 語義で、全件が人の確認前（注釈に「未確認の辞書」と出る）。多義語は候補を併記する
- 他プレイヤーの英語の発言を GPT-6 Luna（`gpt-6-luna`、推論量 none）で日本語に翻訳する（クラウド翻訳を有効にした場合だけ）
- 日本語の返信を英訳し、確認と編集の後にクリップボードへコピーする。ゲームへの貼り付けと送信は自分で行う
- 訳を、ゲームの上に重ねるオーバーレイか、別の独立ウィンドウに表示する（C方式）

ゲームのプロセスには一切触れない（コード挿入、メモリの読み書き、入力の送信、パケットの解析をしない）。ただし、これは Bungie やアンチチートによる許可やアカウントの安全を保証するものではない（仕様書 19 章）。

## 始める前に

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 2004 以降（x64）。開発と確認は Windows 10 22H2 で行った。Windows 11 は未確認 |
| OCR | 「設定」→「時刻と言語」→「言語」で、英語（米国）と日本語の言語機能を入れる。日本語がないと行頭の「[ファイアチーム]宛て:」等を読めない |
| ゲームの表示 | ボーダーレスかウィンドウ表示。排他フルスクリーンではオーバーレイを表示できない |
| クラウド翻訳 | 自分の OpenAI API キー（有料）。使わなくても原文と辞書注釈は表示できる |

## 最初の設定

1. アプリを起動し、「対象を選択(T)…」を押す。Windows の選択画面で Destiny 2 のウィンドウを選ぶ（アプリがウィンドウを自動で探すことはない）。選択中はウィンドウの周りに黄色い枠が出る
2. 「ROI 調整」画面で、プレビュー上のチャット欄をドラッグで囲む。マウスを使わない場合は、左（X）、上（Y）、幅（W）、高さ（H）を数値で入れて「数値で設定(N)」を押す。チャットが消えて囲みにくい時は「プレビューを止める(F)」を使う
3. 「試し読み(T)」で読み取りを確かめ、「保存(S)」を押す
4. 「開始(S)」を押す。取得中はメイン画面の「取得:」が「取得中」になる

ROI はチャット欄の履歴部分だけを囲む。入力欄や、チャット以外の画面表示を含めると、誤った発言が混じることがある。

## クラウド翻訳を使う

1. 「設定(E)…」の「翻訳」タブで、外部へ送る内容を読み、「上記の内容を確認しました」を選ぶ
2. 「クラウド翻訳を有効にする」を選ぶ
3. API キーを入れて「登録・差し替え(K)」を押す。キーは Windows のユーザー単位で暗号化して保存し、画面には再表示しない
4. 「接続確認(C)」で 1 回だけ翻訳を試す（1 回分の利用料が生じ得る）

送るのは発言の本文（名前は P1 等の記号に置き換える）と、辞書の該当項目だけ。「直近の会話を文脈として送る」を選んだ時だけ、直前の数件も送る。OpenAI 側でも予算の上限を設定する。画面の推計額は請求額を保証しない。

## 表示

| 操作 | 方法 |
| --- | --- |
| 独立ウィンドウとオーバーレイの切替 | 「表示切替(O)」、または Ctrl+Alt+O |
| オーバーレイの移動 | 「オーバーレイ配置(L)…」→ ドラッグ → Esc か、もう一度ボタン |
| オーバーレイを隠す・戻す（取得は続く） | Ctrl+Alt+H |
| 文字の大きさ、幅、背景の濃さ、件数 | 「設定(E)…」の「表示」タブ |

オーバーレイは表示専用で、クリックはゲームへ通る。ゲームでもこのアプリでもないウィンドウが前面になると隠れる（設定で変更できる）。

受信履歴の状態は文字でも示す（認識中、認識要確認、翻訳待ち、翻訳済み、要確認、失敗、期限切れ、未翻訳、開始前から表示、訂正）。開始前から表示されていた発言や認識が不安定な発言は自動では送らず、「翻訳」ボタンで個別に翻訳できる。

## 返信

1. 「返信(J)…」か Ctrl+Alt+J で返信画面を開く
2. 日本語で書き、Ctrl+Enter（または「英訳(E)」）で英訳する。Shift+Enter は改行
3. 英訳を確かめ、必要なら直す。「逆翻訳で確認(B)」で日本語に戻して意味を確かめられる（追加の利用料が生じ得る）
4. 「コピー(C)」→ ゲームのチャット欄に貼り付けて、自分で送信する

ゲームのチャット欄は改行を受け付けないため、コピー時に改行は空白に置き換える。英訳中に下書きを変えると、古い英訳で上書きせず「入力が変更されました」と示す。

## 停止と終了

- 「停止(P)」か Ctrl+Alt+T で取得と翻訳を止める（1 秒以内に新しい取得と外部送信が止まる）。もう一度押すと再開する。再開時は見えている発言を新着として翻訳しない
- メイン画面を閉じると終了する。取得を止めてから閉じる

ホットキーが他のアプリと競合して登録できない時は、メイン画面のボタンで同じ操作ができる。ホットキーは「設定(E)…」の「ホットキー」タブで変えられる。

## キーボードと読み上げ

- 主要なボタンにはアクセスキーがある（Alt を押しながら括弧内の文字）。Tab で移動、Space か Enter で押す
- 受信履歴の各行は、時刻、話者、状態、原文、訳の順に読み上げる
- 通知、待機中の表示、返信と設定の状態の変化は、スクリーンリーダーに読み上げを促す
- 色は Windows のシステム色に従い、ハイコントラストの配色でも読める。状態は色だけでなく文字で示す

## 困った時

| 表示 | 意味と対処 |
| --- | --- |
| CAP01 | 取得できない。対象を選び直す。GPU の一時的な問題なら自動で 3 回まで作り直す |
| CAP02 | 対象が閉じたか、新しいフレームが届かない（最小化等）。ゲームを元に戻すか、対象を選び直す |
| CAP03 | 画面の大きさや縦横比が変わった。「ROI 調整(R)…」でやり直す |
| OCR01 | OCR の言語機能がない。英語（米国）と日本語の言語機能を入れる |
| OCR02 | 認識が不安定。ROI を見直すか、チャットが見やすい位置で使う |
| TR01 | API キーが無効か権限がない。「翻訳」タブでキーを確かめる |
| TR02 | 回数の上限、429、予算の上限に達した。時間を置くか、OpenAI の予算を確かめる |
| TR03 | 通信の失敗、時間切れ、5xx。続くと 30 秒止めてから 1 回だけ試す |
| TR04 | 応答の形式が不正、拒否、出力の打ち切り。その発言は訳さない |
| TR05 | gpt-6-luna を使えないか、応答のモデルが違う。別のモデルへは切り替えない |
| DATA01 | 設定や辞書のファイルが不正。既定値で起動し、ファイルは書き換えない |
| UI01 | ホットキーかオーバーレイを使えない。ボタンか独立ウィンドウで操作する |

「予期しないエラーが発生しましたが、処理を続けています」と出た時は、診断記録（下記）に種類が残る。

## 保存されるもの

保存先はメイン画面の診断欄の「保存先」に表示する（インストール版はパッケージの LocalState、開発実行は `%LOCALAPPDATA%\D2ChatTranslator`）。

| ファイル | 内容 |
| --- | --- |
| `settings.json`（と `.bak`） | 設定 |
| `capture-profiles.json` | ROI |
| `secrets.dpapi` | API キー（Windows のユーザー単位で暗号化） |
| `glossary-user.json` | 利用者の辞書（任意） |
| `diagnostics\diag-*.jsonl` | 診断記録。本文、名前、画像、キーは含めない。7 日、合計 30MB まで |

画面の画像と受信履歴は保存しない。診断記録を止めるには、`settings.json` の `diagnostics.level` を `off` にする。

## 長時間の試験（8 時間）と性能の記録

アプリは動いている間、遅延、CPU、メモリ、GPU メモリ、UI の応答遅れ、未処理例外を診断記録に残す（決定 D28）。ゲームで 8 時間使った後、次で判定表を作れる。

```bash
dotnet run --project tools/D2Translator.Eval -- diagnostics --out p5-report.md
```

最も長く動かした実行（セッション）を P01〜P04、P10〜P14 の目標と比べて表にする。件数や時間が足りない項目は「参考」と表示する。結果を共有する前に内容を確かめる（本文は含まれないが、版や設定の値は含まれる）。
