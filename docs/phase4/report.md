# Phase 4 実施記録

仕様書 22 章 Phase 4「C方式、返信入力、コピー、設定を統合」の実施記録。記録日は 2026年10月24日。

## 実装したもの

| 項目 | 内容 | 仕様書 |
| --- | --- | --- |
| C方式 | 独立ウィンドウとオーバーレイを「表示切替」ボタンとホットキーで切り替える。両方式は同じ ViewModel と履歴を参照し、取得と翻訳を表示ごとに起動しない。切替で履歴、返信の下書き、翻訳の待ち行列は変わらない | 4.1、4.2、FR01 |
| オーバーレイ | 別プロセスの最前面ウィンドウ（ゲームの描画に参加しない）。直近の発言（既定 4 件）の訳文と原文、取得が止まっている時はその状態を表示。背景だけを半透明にし、幅、文字の大きさ、不透明度、件数を設定で変えられる | 4.1、11.3 |
| クリック透過 | 表示専用の間は `WS_EX_TRANSPARENT`、`WS_EX_NOACTIVATE`、`WS_EX_TOOLWINDOW` でクリックをゲームへ通し、フォーカスを取らない。操作ボタンは置かない | 11.3 |
| 配置編集 | メイン画面の「オーバーレイ配置…」で開始し、枠と「配置編集中」を表示。ドラッグで移動し、Esc かもう一度ボタンを押すと表示専用に戻って位置を保存する。保存位置が画面外なら可視領域へ戻す | 4.2、11.3 |
| ゲームが前面でない時 | 既定で、ゲームでも自アプリでもないウィンドウが前面になったらオーバーレイを隠す（D24）。取得は続ける | 4.2 |
| 表示できない時 | オーバーレイを作れなければ UI01 を表示し、`display.autoFallback` が有効な時だけ独立ウィンドウへ戻す | 4.2 |
| 映り込み | `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` を試し、結果を診断欄に表示する。取得した行に最近表示した訳文が現れたら、映り込みとして通知する（D25） | 4.3 |
| 返信入力 | 日本語の下書き（IME 対応、Ctrl+Enter で英訳、Shift+Enter で改行、上限 1000 文字）、文体（一般／短く／丁寧）、英訳の編集と文字数、逆翻訳、明示コピー | 10.1、11.4 |
| 下書きの revision | 英訳中に下書きを変えたら、戻った英訳で候補を上書きせず「入力が変更されました」と示す。変更前の英訳を使うかは利用者が選ぶ。手で直した英訳を英訳し直す時は確認する | 10.1、11.4 |
| 返信の英訳 | GPT-6 Luna（`gpt-6-luna`、推論量 none）。下書きの既知の名前は記号にして送り、英訳で元へ戻す。1 行で返すよう指示し、記号と数字の欠落、日本語の残り、改行を検査する。文脈は、翻訳設定で文脈の送信を有効にし、返信画面で「直近の会話を参考にする」を選んだ時だけ添える | 6.3、15.2 |
| 要求の調停 | 外部要求の同時実行は合計 2 件。返信を優先し、返信を連続 3 件通したら待っている受信を 1 件通す。返信の未送信は 2 件まで。回数上限、遮断、キャッシュは受信と共有 | 15.4 |
| コピー | 表示中の英訳だけをクリップボードへ書く。ゲームが改行を受け付けないため改行は空白に置き換えて知らせる。先頭が `/` なら確認する。失敗時は 5 回まで再試行。状態は「コピー済み」までで、送信済みは推測しない | 10.2、10.3 |
| クリップボードの自動消去 | 既定は無効。有効時は指定秒数後、クリップボードの世代番号が本アプリの書込みから変わっていない場合だけ消去する。他のアプリの内容は読まない | 10.3 |
| ホットキー | `RegisterHotKey` で取得の一時停止・再開（Ctrl+Alt+T）、表示方式の切替（Ctrl+Alt+O）、オーバーレイを隠す・表示（Ctrl+Alt+H）、返信画面（Ctrl+Alt+J）。競合したら「未登録」と表示し、ボタンで代替する。キーボードフックは使わない | 11.5 |
| 設定の統合 | 設定画面（表示、取得と OCR、翻訳、返信とクリップボード、ホットキー）に適用、閉じる、既定値に戻すを用意。翻訳のタブは送信内容の確認と API キーを伴うため操作した時点で反映（D26） | 11.4、12 |

## 試験

`dotnet test D2Translator.slnx` で 238 件すべて合格。外部 API は偽の実装だけを使った。

| 観点 | 主な試験 |
| --- | --- |
| 返信の下書き | 英訳中に下書きを変えた時に候補を上書きしないこと、変更前の英訳の明示選択、編集の追跡、1000 文字超で英訳できないこと |
| コピー | 改行の空白への置換と通知、先頭 `/` の確認 |
| 返信の英訳 | 日本語の文中の名前（例: Kestrelさん）の記号化と復元、文体と方向、クラウド無効で送信 0 件、記号・数字・日本語の残り・改行の検査 |
| 調停 | 返信の優先と、連続した返信の後に受信を 1 件通すこと |
| オーバーレイ | 前面ウィンドウによる表示判定、配置編集中と利用者による非表示、自己映り込みの検出 |
| 設定 | ホットキーの解釈（修飾キー必須）、オーバーレイの幅の範囲 |

開発機でアプリを起動し、UI オートメーションで自アプリだけを操作して次を確認した。データ保存先は試験用フォルダーに切り替え（`D2CT_DATA_DIR`）、利用者の設定は変えていない。

| 確認 | 結果 |
| --- | --- |
| 表示方式の切替 | オーバーレイが幅 480 で表示され、独立ウィンドウに戻すと隠れる |
| クリック透過 | 表示専用で `WS_EX_TRANSPARENT` と `WS_EX_NOACTIVATE` が付き、配置編集中は外れ、終了で戻る。位置が保存される |
| ホットキー | 4 つすべて登録できた |
| 返信画面と設定画面 | 表示と各タブの内容 |
| 映り込み除外 | `SetWindowDisplayAffinity` がエラー 8 で失敗した（D25） |

## 修正した不具合

Phase 3 の翻訳設定画面は、クラウド翻訳が有効な状態で開くと、初期化の順序の誤りで「確認なしに有効化された」と判断して無効にし、保存していた。初期値の反映中は変更の処理を行わないよう修正した。Phase 4 の画面確認でこの不具合により開発機の利用者設定が無効に変わったため、元の値（有効）に戻した。
